# Mission Control

Personal command center for tracking ideas, tasks, issues, and events across all areas of life and business.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your phone or desktop.

## Capture Ideas

**From the dashboard:** Use the quick-add bar at the bottom of the screen.

**From Claude Code:** Use the `/idea` skill:
```
/idea Build an automated lead scoring system for wholesale deals
/idea urgent: Fix the broken contact form on acquisitions page
/idea Schedule family dinner for Saturday
```

## Categories

- **Park Acquisitions** — MHP/RV park deals and due diligence
- **Wholesale** — Wholesale real estate deals and team tasks
- **Personal** — Personal projects and goals
- **Family** — Family events and activities

## Item Types

- **Idea** — Feature requests, brainstorms, future possibilities
- **Task** — Actionable to-dos
- **Issue** — Bugs, problems, things that need fixing
- **Event** — Meetings, appointments, scheduled activities
